# 🃏 Tanısan Seversin

> Cihazı elden ele dolaştırın, birbirinizi gerçekten tanıyın.

Tanısan Seversin, tek bir cihaz üzerinden oynanan (pass & play) bir **masa oyunu web uygulamasıdır**. Oyuncular sırayla soruları çeker, cevaplar ve birbirlerini daha yakından tanır.

---

## 🎮 Özellikler

- 🃏 **7 farklı deste kategorisi** — Yeni Tanışma, Arkadaşlar Arası, Flört & İlk Buluşma, Aile, Dirty, NSFW, En Gizli Sırlar
- 🍺 **Alkollü / Alkolsüz mod** — Pas geçen oyuncu shot atar ya da 3 ceza kartı çeker
- 🔀 **Shuffle Bag algoritması** — Aynı soru tekrar çıkmaz
- 🎵 **Sesli efektler** — Kart çekme, cevaplama ve ceza anlarında ses
- 🌈 **Dinamik tema sistemi** — Her kategori için farklı renk paleti
- 📱 **Mobil öncelikli tasarım** — Tek elle rahatça kullanım
- ⚡ **Sıfır bağımlılık** — Vanilla HTML, CSS ve JavaScript

---

## 🚀 Başlamak

Herhangi bir kurulum gerekmez. Sadece tarayıcıda açın:

```
index.html
```

Ya da canlı siteye gidin → **[tanisan-seversin.vercel.app](https://tanisan-seversin.vercel.app)**

---

## 🕹️ Nasıl Oynanır?

1. **Oyuncuları ekleyin** (min. 2 kişi)
2. **Oyun modunu seçin** — Alkollü veya Alkolsüz
3. **Destelerinizi seçin** — İstediğiniz kategorileri işaretleyin
4. **Oyunu başlatın** ve cihazı sırayla dolaştırın
5. Kartı çekin, soruyu sesli cevaplayın
6. Pas geçmek yasak — cezası var! 😈

## 📁 Proje Yapısı

```
tanisan-seversin/
├── index.html      # Ana HTML yapısı (kurulum & oyun ekranları)
├── style.css       # Tüm stiller, temalar ve animasyonlar
├── app.js          # Oyun motoru (state, mantık, UI)
├── questions.js    # Soru bankası (7 kategori)
└── audio.js        # Ses efektleri sistemi
```
