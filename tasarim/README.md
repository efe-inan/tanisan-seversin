# Tasarım Klasörü (tasarim/)

Görsellerinizi bu klasöre ekleyebilirsiniz. Örneğin:

1. **kart-arka.png** (veya .jpg / .webp / .svg)
   - Kartın destede dururken görünen desenli/logolu arkası
   - Önerilen oran: 2.5 : 3.5 (Dikey kart boyutu, örn: 600x840 px)

2. **anasayfa-bg.png** (veya .jpg / .webp / .svg)
   - Oyunun ana arka planı veya masa dokusu
   - Önerilen çözünürlük: 1920x1080 px

3. **kart-on.png** (İsteğe bağlı)
   - Soru tarafının arka plan deseni / çerçevesi
